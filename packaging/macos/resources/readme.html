What gets installed

The stratum command-line tool is installed to /usr/local/lib/stratum and linked as /usr/local/bin/stratum. Nothing else is changed and no network request is made by the installer itself.

Requirements

  • macOS on Intel (x86_64) or Apple silicon (arm64)
  • Python 3.12 or newer (brew install python@3.12)
  • Docker Desktop — only for stratum up / stratum install

Next steps

stratum install    # bootstrap the local stack (compose + .env, pull image)
stratum up         # start the stack (docker compose up -d)
stratum status     # container + health summary
stratum doctor     # environment diagnostics
