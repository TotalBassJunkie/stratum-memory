Stratum-Memory

This installer places the stratum command-line tool on your Mac:

  • /usr/local/lib/stratum — the CLI and its runtime
  • /usr/local/bin/stratum — the launcher on your PATH

The CLI needs Python 3.12 or newer at runtime. If it is missing, install it first: 

brew install python@3.12

This installer only adds the CLI. The Docker stack (Postgres + pgvector) is bootstrapped afterwards by running stratum install.
